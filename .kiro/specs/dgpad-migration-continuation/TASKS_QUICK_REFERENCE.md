## Cómo Ejecutar una Tarea

### Patrón por Feature (Ejemplo: Board Points)

1. **Crear Tipos** (Tarea 2.1)
   - Archivo: `src/app/features/board-points/board-points-types.ts`
   - Basarse en design.md sección 3.1
   - Exportar tipos para usar en tests

2. **Crear Componente** (Tarea 2.2)
   - Archivo: `src/app/features/board-points/board-points-panel/`
   - Template HTML con inputs y botón
   - Component TypeScript con lógica
   - Inyectar DgpadBridgeService

3. **Implementar Bridge** (Tarea 2.3)
   - Agregar método en `DgpadBridgeService`
   - Crear script JavaScript en `public/dgpad-legacy-host.html`
   - Validación y error handling

4. **Tests** (Tareas 2.4-2.7)
   - Unit tests con mocks
   - Property tests con fast-check
   - Integration tests
   - Manual testing en Chrome

## Preguntas Frecuentes

**P: ¿Por dónde empiezo?**
R: Por Fase 1 (Preparación). Toma ~8 horas y prepara todo lo necesario.

**P: ¿Puedo ejecutar tareas en paralelo?**
R: Sí, dentro de la misma onda del DAG. Pero no saltees fases.

**P: ¿Qué pasa si un test falla?**
R: Vuelve al código, arréglalo, re-run tests. Itera hasta que pasen.

**P: ¿Coverage mínimo?**
R: 80% en componentes, 90% en bridge. No negociable.

**P: ¿Cuánto tiempo lleva?**
R: 94 horas. Con 10h/semana = 9-10 semanas. Con 15h/semana = 6-7 semanas.
